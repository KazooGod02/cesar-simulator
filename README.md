# CÉSAR SIMULATOR

Clicker tycoon 8-bit de humor adulto (**+18, sin contenido explícito**): albures, doble sentido y un hombre que no puede parar... sin cesar.

César, de 27 años, vive encerrado en su cuarto de Culiacán con su computadora y su novia de toda la vida: Manuela (su mano derecha).

## Controles

| | PC | Móvil |
|---|---|---|
| Caminar | ← → / A D | Botones ◀ ▶ |
| Usar objeto | E / Enter | Botón USAR o tocar el objeto |
| Clic en la PC | Espacio / clic | Tocar "Darle play" o los videos |
| Cambiar sitio | 1 2 3 | Pestañas |
| Tiendita / Menú | T / M | Botones |
| Salir / levantarse | Esc | Botón ✕ / Levantarse |

## Cómo se juega

- **PC:** tres sitios parodia (CajaNaranja, Ekis, TresEquis) con más ganancia y más riesgo. Los clics seguidos hacen **racha** (hasta x2) y a veces salen **críticos**. Cierra los anuncios para ganar bonos.
- **Necesidades:** 😴 sueño (cama), 💧 hidratación (botellón) y ⚡ energía (tapete para estirarse). Bajan lento; debajo de 25% rindes menos y en 0 César se desploma.
- **Eventos:** mamá, la abuela, el casero, los Testigos... machaca **¡DISIMULA!** antes de que se acabe el tiempo.
- **Historia:** 7 capítulos. El cuarto se va llenando de desorden y cosas nuevas.
- **Confesión (menú):** prestigio. Reinicias con un bono permanente.
- **Ciclo de día y noche** con clima que cambia cada día y la hora en pantalla.

## Subir a GitHub Pages

1. Crea un repo nuevo (por ejemplo `cesar-simulator`) y sube `index.html` a la raíz.
2. En **Settings → Pages**, elige la rama `main` y la carpeta `/ (root)`.
3. El juego quedará en `https://TU-USUARIO.github.io/cesar-simulator/`.

El progreso se guarda en el navegador (localStorage).
